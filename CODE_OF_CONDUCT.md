# Code of conduct

## The short version

Be straight with people. Argue with the work, not the person doing it. Assume the other party is
acting in good faith until they give you a concrete reason not to.

## What is expected

- Say what you measured, and say what you are guessing. Both are welcome; conflating them is not.
- Disagree specifically. "This is wrong" is not useful; "this is wrong because the value it
  compares against is stale by an hour" is.
- Accept a correction the same way you would like one accepted.

## What is not

Harassment, personal attacks, discrimination, sexualised language, publishing anyone's private
information, and sustained disruption of a discussion. Also: pull requests and issues opened to
place links, promote a product, or farm activity.

## Scope

This repository — issues, pull requests, commits and reviews — and any space where someone is
representing the project.

## Enforcement

Report to **hello@coinliqui.com**. Reports are read by the one person who maintains this project
and are kept private. Responses range from a reply explaining what was wrong, to editing or
removing a comment, to blocking an account, depending on what happened.

There is no committee and no appeals process, which is a limitation worth stating rather than
implying otherwise.
